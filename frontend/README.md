# Rent Manager — frontend

Electron + React 19 + TypeScript + Vite. Опис проєкту, архітектура та запуск — у [кореневому README](../README.md), робочі інструкції (збірка `.exe`, режими `.env`, реліз) — у [docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md).

```powershell
npm install
copy .env.development.example .env.development
npm run dev:all     # Django (8001) + Vite (5173) + Electron
```
